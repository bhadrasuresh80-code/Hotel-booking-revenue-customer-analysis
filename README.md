# Hotel-booking-revenue-customer-analysis
#Hotel Booking Revenue and Customer Analysis

##Project Overview

This project analyses hotel booking data to understand revenue performance, booking trends and customer behaviour.

The project uses Python, SQL and Power BI to perform data cleaning, exploratory data analysis, database querying and interactive dashboard development.

##Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL (SQLite)
- Power BI

##Project Workflow

1. Generate hotel booking data using Python.
2. Clean the dataset and handle missing or invalid records.
3. Perform exploratory data analysis using Python.
4. Store and analyse booking data using SQLite.
5. Create visualisations to identify booking and revenue trends.
6. Import the cleaned CSV dataset into Power BI.
7. Develop an interactive Power BI dashboard.

##Key Analysis Areas

- Hotel revenue analysis
- City-wise booking performance
- Booking channel analysis
- Booking status analysis
- Room type and average daily rate analysis
- Customer booking patterns

##Project Files

- Python notebook: Data generation, cleaning and analysis.
- Power BI file: Interactive dashboard.
- Cleaned CSV: Processed booking dataset (if included).

##Objective

To demonstrate practical data analytics skills using Python, SQL and Power BI, and generate useful insights from hotel booking data.
